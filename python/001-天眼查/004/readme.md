
## 文件说明
```
001.py
    * 第四版爬虫程序
    * 每次只爬取三个市的数据, 避免被封
    * 遇到已经存在的年份或省份的数据, 跳过
    * 每爬取完一年的数据需要使用 002.sh 合并, 才能获取下一年的数据
002.sh
    * 将相同年份的数据合并成一个文件
*.csv
    * 汇总后的数据文件
old
    * 临时数据或废弃数据
```

## 数据说明
满足以下条件的企业数
```
年份: 2010-2025
省份: 山西省的各个市
行业: 
    医药制造业
    铁路、船舶、航空航天和其他运输设备制造业
    专用设备制造业
    电气机械和器材制造业
    计算机、通信和其他电子设备制造业
    仪器仪表制造业
登记状态: 存续
企业规模: 大型 中性 小型
```
