
## 1. 为什么存在用户
* 要登录一个系统, 肯定需要一个名称, 用以区分不同的用户

## 2. 为什么存在组
* 为了多个用户之间共享数据


## 3. 用户名称, 用户ID(UID), 组名称, 组ID(GID) 之间的关系
* 一个用户名称只能对应一个用户ID
* 多个用户名称可以对应一个用户ID
* 一个组名称只能对应一个组ID
* 多个组名称可以对应一个组ID
* 一个用户可以对应多个组, 但只能有一个主组

## 4. 为什么存在用户ID和组ID
* 节省空间
* 提高比较的效率
