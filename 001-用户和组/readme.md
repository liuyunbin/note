
## 1. 为什么存在用户
* 要登录一个系统, 肯定需要一个名称, 用以区分不同的用户

## 2. 为什么存在组
* 为了多个用户之间共享数据

## 3. 用户名称, 用户ID(UID), 组名称, 组ID(GID) 之间的关系
* 一个用户名称只能对应一个用户ID
* 多个用户名称可以对应一个用户ID
* 一个组名称只能对应一个组ID
* 多个组名称可以对应一个组ID
* 一个用户可以对应多个组, 但只能有一个主组

## 4. 为什么存在用户ID和组ID
* 节省空间
* 提高比较的效率

## 5. 登录用户, 实际用户, 有效用户, 实际组, 有效组
* 登录用户:
    * 通过终端或ssh登录的用户
    * 登录后不会再变化
* 实际用户:
    * 一般和登录用户相同
    * 可通过 su sudo 切换
* 有效用户:
    * 一般和实际用户相同
    * 可通过 su sudo 切换
    * 当设置了设置组ID时(SUID), 执行 exec 时, 有效用户会变成程序的所有者, 比如 passwd

## 6. 文件权限
* 读, 写, 执行
* 在目录下新增或删除文件时, 至少拥有此目录的写和执行权限
* SUID
    * 二进制文件: 程序的执行者拥有程序所有者的权限
    * 其他文件没意义
* SGID
    * 二进制文件: 程序的执行者拥有程序所属组的权限
    * 目录: 新增的文件所属的组是此目录所属的组
    * 其他文件没意义
* SBIT
    * 目录: 此目录下的内容只有文件所有者 或 目录所有者 或 root 用户才能删除
    * 其他文件没意义

## 7. 权限检验
```
if 进程的有效用户 == root:
    几乎拥有所有权限
else if 进程的有效用户 == 文件的所有者:
    判断文件所属用户的权限
else if 进程的有效组和附属组中是 包含文件所属的组:
    判断文件所属组的权限
else
    判断 other 权限
fi
```
