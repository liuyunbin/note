
## 文件说明
```
001.py
    * 第三版爬虫程序
    * 每次只爬取三个市的数据, 避免被封
    * 遇到已经存在的年份或省份的数据, 跳过
    * 每爬取完一年的数据需要使用 002.sh 合并, 才能获取下一年的数据
002.sh
    * 将相同年份的数据合并成一个文件
*.csv
    * 汇总后的数据文件
old
    * 临时数据或废弃数据
```
